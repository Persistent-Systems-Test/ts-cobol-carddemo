CardDemo — Code Node Graph

Persistent-Systems-Test/ts-cobol-carddemo is a mainframe credit card management application (COBOL, CICS, VSAM, JCL, with optional IMS DB, DB2 and IBM MQ modules) used to exercise migration and modernization tooling. Nodes are code artifacts (online CICS programs in app/cbl, batch programs, JCL jobs in app/jcl, VSAM/sequential datasets and external subsystems); edges are calls (XCTL/LINK), file reads/writes and job submissions/executions.
